# AI-BASED-RECOMMENDATION-SYSTEM

## PROJECT OVERVIEW

This project implements a simple AI-Based Recommendation System using Java. The system recommends products to users based on their preferences and sample rating data. The project demonstrates the basic concept of recommendation engines used in e-commerce, streaming platforms, and content recommendation systems.

## FEATURES

- Product Recommendation
- User Preference Analysis
- Sample Dataset Integration
- Category-Based Suggestions
- Java Implementation
- Apache Mahout Dependency Included

## TECHNOLOGIES USED

- Java
- Apache Mahout
- Maven
- CSV Dataset

## HOW TO RUN

Compile:

javac RecommendationSystem.java

Run:

java RecommendationSystem
